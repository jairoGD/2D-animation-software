# 2D-animation-software
A lightweight 2D drawing and animation tool made for creating hand-drawn animations, sprites and game assets directly in the browser.

https://jairogd.github.io/2D-animation-software/

## Features

* 2D drawing and painting tools
* Frame-by-frame animation
* Animation timeline
* Adjustable animation FPS
* Onion skinning
* Layer-based workflow
* Zoom and canvas navigation
* Video import for rotoscoping/reference
* Sprite sheet export
* Tools for creating seamless textures and tiles
* Designed for game asset creation
* Runs directly in the browser

## Rotoscoping

Videos can be imported and used as animation reference, making it easier to create frame-by-frame animations based on real movement.

## Sprite Sheet Export

Finished animations can be exported as sprite sheets for use in game engines and other projects.

## Seamless Texture Tools

The editor also includes tools for creating repeating textures and tiles, useful for environments, materials and 2D games.

## Purpose

This project was created as a simple personal alternative to heavier drawing and animation software, focused mainly on workflows useful for game development.

## Run

Open the project in a modern web browser.

No installation is required when using the hosted version.
