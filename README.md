# Illustra *(working title)*

A lightweight browser-based **2D drawing and frame-by-frame animation software**.

🔗 **Open Illustra:**
https://jairogd.github.io/2D-animation-software/

No installation required.

## Features

* Drawing tools: Pencil, Brush, Eraser, Fill, Eyedropper, Line, Rectangle and Ellipse
* Curve Tool inspired by the classic MS Paint workflow
* Lasso, rectangular selection and Magic Wand
* Multiple layers
* Layer opacity and blend modes
* Undo / Redo
* Zoom and canvas navigation
* Adjustable anti-aliasing
* Color adjustments
* Image import
* Video import for rotoscoping

## Animation

* Frame-by-frame animation timeline
* Adjustable FPS
* Playback and looping
* Onion Skin
* Multiple animation layers
* Copy / paste / clear frames
* Adjustable animation length

## Export

Animations can be exported as:

* PNG frame sequence
* WebM video
* Animated GIF
* Sprite Sheet

Individual images can also be exported as PNG.

## Curve Tool

The Curve Tool follows the workflow used by older versions of Microsoft Paint:

**Draw a line → bend it once → bend it again**

This provides a fast way to create clean and controlled curved lines using either a mouse or drawing tablet.

## Browser-based

Illustra runs directly in the browser, making it easy to use from different computers without installing additional software.

## Project status

This is mainly a personal drawing and animation tool, but the project is public and free to use.
